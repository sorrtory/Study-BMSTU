## BMSTU. Операционные системы

<img align=right src="https://avatars.githubusercontent.com/u/1056142?v=40" height="50px" width="50px">

This course was about low level programming Unix-like and DOS-like both. We wrote some basic drivers for OpenBSD and ReactOS.

Build tutorials are in [manual](Manual/manual.pdf), drivers' code is partly generated and partly copied from sources.

Each lab had two parts: ReactOS and OpenBSD. \
Each lab has a report. But here is a quick gist anyway:

1. [Lab1](./Labs/Lab1/lab1.pdf) is about compiling kernel with your surname in the system debug at startup
2. [Lab2](./Labs/Lab2/lab2.pdf) is about creating a hello world driver
3. [Lab3](./Labs/Lab3/lab3.pdf) is about implementing a "ps aux" as a driver that can be loaded and unloaded
4. [Lab4](./Labs/Lab4/lab4.pdf) is about drivers with virtual memory. Create 10 virt pages and print some adresses
