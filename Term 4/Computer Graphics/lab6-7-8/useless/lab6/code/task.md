# Лабораторная работа №6 – построение реалистичных изображений

## Задание

1. **Базовая лабораторная работа**  
    Лабораторная работа №3 (модельно-видовые преобразования и преобразования проецирования).

2. **Параметры модели освещения**  
    Определить параметры модели освещения OpenGL:  
    - Свойства источника света.  
    - Свойства материалов (поверхностей).  
    - Характеристики глобальной модели освещения.

3. **Методы повышения реалистичности**  
    Исследовать один из методов повышения реалистичности изображений сцены:  
    - **А3**: Влияние параметров (компонентов модели освещения) источника света.

4. **Алгоритмы анимации**  
    Реализовать один из алгоритмов анимации:  
    - **Б2**: Моделирование движения тела (с заданной начальной скоростью) при условии абсолютно упругого отражения объекта от границ некоторого ограничивающего объема (регулярной формы).

5. **Наложение текстуры**  
    Реализовать наложение текстуры (загрузка из файла *.bmp или процедурная генерация) с возможностью отключения:  
    - **В1**: Использование текстуры для определения интенсивности поверхности.
