\addcontentsline{toc}{section}{Постановка задачи}
\section*{Постановка задачи}\label{Sect::goal}
Целью данной лабораторной работы является разработка модели «сущность-связь».
Для достижения поставленной цели необходимо решить следующие задачи:
\begin{itemize}
    \item  Выбрать предметную область, соответствующую 4-5 сущностям. 
    \item  Сформировать требования к предметной области. 
    \item  Создать модель «сущность-связь» для предметной области с обоснованием выбора кардинальных чисел связей.
\end{itemize}

\addcontentsline{toc}{section}{Практическая реализация}
\section*{Практическая реализация}\label{Sect::implementation}

\addcontentsline{toc}{subsection}{Предметная область и требования}
\subsection*{Предметная область и требования}
В качестве предметной области была выбрана поликлиника. Каждый пациент может записаться на прием к врачу, врач может заполнить результат обследования, а также назначить рекомендации. Система предназначена для автоматизации основных процессов медицинского учреждения: ведения учета врачей и пациентов, организации записей на прием и сдачу анализов, документирования результатов осмотров и выписанных лекарственных назначений.

\addcontentsline{toc}{subsection}{ER модель}
\subsection*{ER Модель}

\paragraph{Сущность «Doctor» (Врач)}
Хранит информацию о медицинских работниках поликлиники.
\begin{itemize}
    \item \textbf{Атрибуты:}
    \begin{itemize}
        \item \textit{Идентификатор}
            \begin{itemize}
                \item \texttt{email} – Адрес электронной почты.
            \end{itemize}

        \item \texttt{name} – ФИО врача.
        \item \texttt{specialization} – Специализация врача.
        \item \texttt{phone\_number} – Контактный телефон.
        \item \texttt{status} – Статус врача (например, работает/болеет/в отпуске).
    \end{itemize}
\end{itemize}

\paragraph{Сущность «Patient» (Пациент)}
Хранит информацию о пациентах, зарегистрированных в поликлинике.
\begin{itemize}
    \item \textbf{Атрибуты:}
    \begin{itemize}
        \item \textit{Идентификатор}
            \begin{itemize}
                \item \texttt{insurance\_number} – Номер страхового полиса.
            \end{itemize}

        \item \texttt{name} – ФИО пациента.
        \item \texttt{phone\_number} – Контактный телефон.
        \item \texttt{date\_of\_birth} – Дата рождения.
        \item \texttt{home\_address} – Домашний адрес.
        \item \texttt{email} – Адрес электронной почты.
        \item \texttt{emergency\_contact} – Контакт для экстренной связи.
        \item \texttt{status} – Статус пациента (например, активен/неактивен).
    \end{itemize}
\end{itemize}

\paragraph{Сущность «Appointment» (Прием)}
Задает расписание приемов у врачей.
\begin{itemize}
    \item \textbf{Атрибуты:}
    \begin{itemize}
        \item \textit{Идентификатор}
            \begin{itemize}
                \item \texttt{schedule\_date} – Дата и время приема.
                \item \texttt{doctor} - Врач, проводящий прием.
            \end{itemize}
        \item \texttt{patient} - Пациент, записанный на прием.
        \item \texttt{address} – Адрес проведения приема.
        \item \texttt{room\_number} – Номер кабинета.
        \item \texttt{examination} – Информация об обследовании на приеме.
        \item \texttt{status} – Статус приема (например, без пациента/проведен/отменен/пациент не явился).
    \end{itemize}
\end{itemize}

\paragraph{Сущность «Prescription» (Рецепты)}
Фиксирует рецепты на лекарства, выписанные врачом пациенту.
\begin{itemize}
    \item \textbf{Атрибуты:}
    \begin{itemize}
        \item \textit{Идентификатор}
            \begin{itemize}
                \item \texttt{prescription\_number} – Номер рецепта, относительно доктора.
                \item \texttt{doctor} - Доктор выписавший рецепт.
            \end{itemize}
        \item \texttt{patient} - Пациент, которому выписан рецепт.
        \item \texttt{prescribe\_date} – Дата выписки рецепта.
        \item \texttt{recommendations} – Рекомендации врача.
        \item \texttt{drug\_name} – Наименование лекарственного препарата.
        \item \texttt{dosage} – Дозировка препарата.
        \item \texttt{frequency} – Частота приема.
        \item \texttt{duration} – Продолжительность курса лечения.
    \end{itemize}
\end{itemize}

\paragraph{Сущность «Assay» (Анализы)}
Фиксирует факт проведения и результаты анализов или других анализов.
\begin{itemize}
    \item \textbf{Атрибуты:}
    \begin{itemize}
        \item \textit{Идентификатор}
            \begin{itemize}
                \item \texttt{assay\_number} – Номер анализа относительно пациента.
                \item \texttt{patient} - Пациент, которому назначен анализ.
            \end{itemize}
        \item \texttt{doctor} - Доктор взявший анализ.
        \item \texttt{sample\_type} – Тип образца.
        \item \texttt{test\_date} – Дата взятия образца.
        \item \texttt{results} – Результаты анализа.
        \item \texttt{status} – Статус анализа (готов/в процессе/отменен).
        \item \texttt{reference\_range} – Референсные значения.
        \item \texttt{is\_urgent} – Признак срочности обработки анализа.
    \end{itemize}
\end{itemize}

\paragraph{Обоснование кардинальных чисел связей}
\begin{itemize}

    % Doctor ---
    \item \textbf{Appointment <--> Doctor} Один-ко-многим
    \begin{itemize}
        \item \textbf{Appointment --> Doctor} 1:1. Один прием может у одного и только одного врача
        \item \textbf{Appointment <-- Doctor} 0:N. Один доктор может вести несколько приемов, а может не иметь их вообще
    \end{itemize}

    \item \textbf{Prescription <--> Doctor} Один-ко-многим
    \begin{itemize}
        \item \textbf{Prescription --> Doctor} 1:1. Один рецепт может быть выписан только одним врачом.
        \item \textbf{Prescription <-- Doctor} 0:N. Один доктор может выписать несколько рецептов, но вообще не обязан их выписывать
    \end{itemize}

    \item \textbf{Assay <--> Doctor} Один-ко-многим
    \begin{itemize}
        \item \textbf{Assay --> Doctor} 0:1. Один анализ может быть проведен только одним врачом, но пока его нет, врач не назначен
        \item \textbf{Assay <-- Doctor} 0:N. Один доктор может провести несколько анализов, но вообще не обязан их проводить
    \end{itemize}


    % Patient ---
    \item \textbf{Appointment <--> Patient} Один-ко-многим
    \begin{itemize}
        \item \textbf{Appointment --> Patient} 1:1. Один прием может быть у только одного пациента
        \item \textbf{Appointment <-- Patient} 0:N. Один пациент может записаться на несколько приемов, но вообще не обязан иметь эти записи
    \end{itemize}

    \item \textbf{Prescription <--> Patient} Один-ко-многим
    \begin{itemize}
        \item \textbf{Prescription --> Patient} 1:1. Один рецепт может быть выписан только одному пациенту.
        \item \textbf{Prescription <-- Patient} 0:N. Один пациент может получить несколько рецептов, но вообще не обязан их получать
    \end{itemize}

    \item \textbf{Assay <--> Patient} Один-ко-многим
    \begin{itemize}
        \item \textbf{Assay --> Patient} 1:1. Один анализ может быть проведен только одному пациенту.
        \item \textbf{Assay <-- Patient} 0:N. Один пациент может пройти несколько анализов, но вообще не обязан их проходить
    \end{itemize}
\end{itemize}
