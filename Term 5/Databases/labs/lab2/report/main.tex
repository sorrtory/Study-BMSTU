\end{itemize}

% Обоснование кардинальных чисел свойств
\paragraph{Обоснование кардинальных чисел свойств}
Кардинальные числа, указанные в нижних индексах атрибутов и связей, отражают минимальное и максимальное количество экземпляров, которые могут быть связаны с данной сущностью или атрибутом. Приведу пояснения для основных свойств, соответствующих актуальной модели:

\begin{itemize}
    \item \textbf{Doctor}: 
    \begin{itemize}
        \item \textbf{email} (1,1) - Каждый врач должен иметь уникальный адрес внутренней почты поликлиники.
        \item \textbf{name} (1,1) - ФИО врача обязательно.
        \item \textbf{specialization} (1,1) - Врач может иметь только одну специализацию.
        \item \textbf{phone\_number} (1,1) - Контактный телефон является обязательным.
        \item \textbf{status} (1,1) - Статус врача обязателен для определения его текущего состояния.
        \item \textbf{patient\_assay} (0,N) - Врач может проводить анализы пациентам в любом количестве, но не обязательно.
        \begin{itemize}
            \item \textbf{assay\_number} (1,1) - Номер анализа обязателен для идентификации.
            \item \textbf{Patient} (1,1) - Пациент, которому назначен анализ.
        \end{itemize}
        \item \textbf{Prescription} (0,N) - Врач может выписывать рецепты в любом количестве, но не обязательно.
        \begin{itemize}
            \item \textbf{prescription\_number} (1,1) - Номер рецепта обязателен для идентификации.
            \item \textbf{prescribe\_date} (1,1) - Дата выписки рецепта обязательна.
            \item \textbf{recommendations} (0,1) - Рекомендации врача могут быть указаны, но не обязательно.
            \item \textbf{drug\_name} (1,1) - Наименование препарата обязательно.
            \item \textbf{drug\_recipe} (0,1) - Рецептурная информация может быть указана, но не обязательно.
            \item \textbf{dosage} (0,1) - Дозировка может быть указана, но не обязательно.
            \item \textbf{frequency} (0,1) - Частота приема может быть указана, но не обязательно.
            \item \textbf{duration} (0,1) - Продолжительность курса лечения может быть указана, но не обязательно.
            \item \textbf{status} (1,1) - Статус рецепта обязателен для понимания его актуальности.
            \item \textbf{Patient} (1,1) - Каждый рецепт должен быть связан с пациентом, которому он выдан.
        \end{itemize}
        \item \textbf{Appointment} (0,N) - Врач может проводить приемы в любом количестве, но не обязательно.
        \begin{itemize}
            \item \textbf{appointment\_number} (1,1) - Порядковый номер приема обязателен для идентификации.
            \item \textbf{schedule\_date} (1,1) - Дата и время приема обязательны для планирования.
            \item \textbf{address} (1,1) - Адрес проведения приема должен быть указан, чтобы пациент знал место (филиал) проведения приема.
            \item \textbf{room\_number} (1,1) - Номер кабинета должен быть указан, чтобы пациент знал, куда конкретно приходить.
            \item \textbf{examination} (0,1) - Информация о осмотре может быть указана врачом, но это не обязательно.
            \item \textbf{status} (1,1) - Статус приема обязателен для понимания факта его проведения.
            \item \textbf{Patient} (0,1) - Каждый прием должен быть связан с одним пациентом, который на него записался, но если он еще не записан, то информации о записи нет.
        \end{itemize}
    \end{itemize}
    
    \item \textbf{Patient}:
    \begin{itemize}
        \item \textbf{insurance\_number} (1,1) - Номер страхового полиса обязателен для идентификации пациента.
        \item \textbf{name} (1,1) - ФИО пациента обязательно.
        \item \textbf{phone\_number} (1,1) - Контактный телефон обязателен.
        \item \textbf{date\_of\_birth} (0,1) - Дата рождения выдается пациентом по желанию для его удобства.
        \item \textbf{home\_address} (0,1) - Адрес может быть также указан, но не обязателен.
        \item \textbf{email} (1,1) - Электронная почта обязательна для связи с пациентом.
        \item \textbf{emergency\_contact} (0,1) - Контакт для экстренной связи может быть указан, но не обязателен.
        \item \textbf{doctor\_prescription} (0,N) - Пациент может получить несколько рецептов от врачей, но не обязательно.
        \item \textbf{status} (1,1) - Статус пациента обязателен для определения его текущего состояния.
        \begin{itemize}
            \item \textbf{packages\_number} (1,1) - Номер рецепта обязателен для идентификации.
            \item \textbf{Doctor} (1,1) - Врач, который выписал рецепт.
        \end{itemize}
        \item \textbf{doctor\_appointment} (0,N) - Пациент может записаться на прием к врачу любое количество раз, но не обязательно.
        \begin{itemize}
            \item \textbf{schedule\_date} (1,1) - Дата и время приема обязательны для планирования.
            \item \textbf{Doctor} (1,1) - Врач, к которому записан пациент.
        \end{itemize}
        \item \textbf{Assay} (0,N) - Пациент может пройти несколько анализов, но не обязательно.
        \begin{itemize}
            \item \textbf{assay\_number} (1,1) - Номер анализа обязателен для идентификации.
            \item \textbf{sample\_type} (1,1) - Тип образца обязателен для понимания, какой анализ проводится.
            \item \textbf{test\_date} (1,1) - Дата взятия образца обязательна для отслеживания сроков.
            \item \textbf{results} (0,1) - Результаты анализа появляются после проведения, но изначально могут отсутствовать.
            \item \textbf{status} (1,1) - Статус анализа обязателен для понимания текущего состояния.
            \item \textbf{reference\_range} (0,1) - Референсные значения могут быть указаны врачом для интерпретации результатов.
            \item \textbf{is\_urgent} (1,1) - Обязательный признак срочности анализа обязателен для определения приоритетности выполнения.
            \item \textbf{Doctor} (0,1) - Каждый анализ должен быть связан с врачом, который его взял, но если анализ еще не взят, то информации о враче нет.
        \end{itemize}
    \end{itemize}
\end{itemize}
