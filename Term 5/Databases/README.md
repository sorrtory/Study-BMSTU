# Databases course

<img align=right src="https://upload.wikimedia.org/wikipedia/commons/thumb/4/41/Microsoft_SQL_Server_2025_icon.svg/2560px-Microsoft_SQL_Server_2025_icon.svg.png" height="50px" width="50px">

This course covers the fundamentals of database systems.

We studied concepts of designing databases, learned about internal DMBS architecture and mechanisms. Touched different approaches of storing data. Practiced writing sql scripts on SQL server.

[Tasks](./task/) and theory are inside the [lectures](./lectures/new)
