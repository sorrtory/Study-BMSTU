# Formal Languages Theory

<img align=right src="https://web.cs.ucdavis.edu/~rogaway/classes/120/spring14/pl.jpg" height="50px" width="50px">

This course was about formal languages, automata theory and regular expressions.
We solved dozens of tasks about language classification and wrote several labs implementing various automata and grammars.

[Here](./obsidian/) is my obsidian vault.
There are my notes about basic concepts of formal languages theory.

Note that lots of materials are taken from the course repository. 
And it is essential to check all the [links](https://github.com/TonitaN/FormalLanguageTheory?tab=readme-ov-file#%D0%B4%D0%B0%D0%BB%D1%8C%D1%88%D0%B5-%D0%B8%D0%B4%D1%83%D1%82-%D0%B8%D1%81%D0%BA%D0%BB%D1%8E%D1%87%D0%B8%D1%82%D0%B5%D0%BB%D1%8C%D0%BD%D0%BE-%D1%82%D1%80%D1%83%D0%B4%D1%8B-%D1%81%D1%82%D1%83%D0%B4%D0%B5%D0%BD%D1%82%D0%BE%D0%B2-%D0%BA%D0%B0%D1%84%D0%B5%D0%B4%D1%80%D1%8B-%D0%B8%D1%839) given there first.

### Labs

- [Lab1](./srs/labs/lab1/README.md) is about string rewriting systems (SRS)
- [Lab2](./srs/labs/lab2/README.md) is about finite automatas (NFA, DFA, AFA) and regex
- [Lab4](./srs/labs/lab4/README.md) is about extended regex (with backreferences)

### RK

There were two tests that basically covered language classification, pumping lemma in particular.

- [RK1](./srs/rk/rk1/README.md) is about pumping lemmas for regular and context-free languages
- [RK2](./srs/rk/rk2/README.md) is about the same but harder and also have attribute grammar task
