
**Фундированный порядок** (Well-founded order) - это порядок, в котором у любого непустого подмножества есть наименьший элемент. То есть система не содержит бесконечных убывающих цепочек. Как например, на множестве натуральных чисел с обычным порядком.


## Примеры

### Примеры порядков, которые не являются фундированными:
- На множестве целых чисел с обычным порядком (например, бесконечная убывающая цепочка: 0 > -1 > -2 > ...).

### Примеры фундированных порядков:
- На множестве натуральных чисел с обычным порядком (каждое непустое подмножество имеет наименьший элемент).
- Лексикографический порядок на словах над конечным алфавитом (каждое непустое множество слов имеет наименьшее слово по лексикографическому порядку). Пример: множество слов { "b", "ba", "a" } имеет наименьшее слово "a". То есть слово "a" лексикографически меньше "b" и "ba", а "b" меньше "ba".

### Lexicographical Order
Compares words character by character, like a dictionary.
If one word is a prefix of another, the shorter word comes first.
Example: "a" < "ab" < "b"
### Shortlex Order
First compares by length: shorter words come before longer words.
If lengths are equal, uses lexicographical order.
Example: "a" < "b" < "ab"
