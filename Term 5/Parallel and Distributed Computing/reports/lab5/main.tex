\section*{Постановка задачи}\label{Sect::goal}
\begin{enumerate}
    \item \textbf{Использование барьерной синхронизации — задача «эволюция».}\\
        Реализовать параллельную модель клеточного автомата на прямоугольной матрице размеров M \(\times\) K:
        \begin{itemize}
            \item Каждая клетка содержит 0 или 1; начальная матрица заполняется случайно.
            \item Правила эволюции стандартные (см. условие): у живой клетки меньше 2 соседей — смерть, 2 или 3 — выживает, больше 3 — смерть; пустая клетка с ровно 3 соседями становится живой.
            \item Граничные клетки имеют тороидальную геометрию (соседи с противоположной стороны).
            \item Запустить заданное число шагов T моделирования при помощи n потоков. Каждый поток отвечает за непрерывную горизонтальную (или вертикальную) полосу матрицы. Результаты шага вычисляются в отдельной «новой» матрице.
            \item После завершения вычисления шага все потоки синхронизировать барьером; затем содержимое новой матрицы копируется в исходную (копирование может выполняться потоками параллельно при соблюдении барьера).
            \item Поскольку поток видит только свою полосу, при обращении к элементам, лежащим за границей своей полосы, он должен получить их у соседних потоков (реализовать обмен граничными полосами через каналы/общую структуру с синхронизацией или читать соседние границы перед началом шага).
            \item Измерить среднее время одного шага при параллельной реализации (различные n) и сравнить со средней длительностью шага однопоточной реализации на том же входе. В отчёте привести методику измерения, таблицу результатов и краткий вывод.
        \end{itemize}

    \item \textbf{Использование синхронизаций чтения и записи (reader/writer).}\\
        Написать программу, в которой n потоков генерируют по R псевдослучайных чисел в диапазоне [0,1000] и пытаются помещать их в конец однонаправленного связного списка только если такого числа там ещё нет:
        \begin{itemize}
            \item Поиск наличия числа в списке выполнять под общей блокировкой чтения (shared/read lock).
            \item Если число не найдено, перейти к блокировке записи (exclusive/write lock), и перед вставкой повторно проверить отсутствие числа (возможна «гонка» между чтением и захватом записи).
            \item Вставлять новый элемент в конец списка только под записью.
            \item По завершении всех потоков основной поток должен пройти по списку и проверить отсутствие повторяющихся значений.
            \item В отчёте привести исходный код программы и короткий отчёт о проверке корректности (например, длина списка и отсутствие дубликатов).
        \end{itemize}
\end{enumerate}

use rand::rngs::StdRng;
use rand::{Rng, SeedableRng};
use std::sync::{
    Arc, Barrier,
    atomic::{AtomicU8, Ordering},
};
use std::thread;
use std::time::Instant;

const ROWS: usize = 4096;
const COLS: usize = 4096;
const STEPS: usize = 1; // количество шагов эволюции
const THREADS: usize = 16;
const SEED: u64 = 1; // сид для генератора случайных чисел

#[inline(always)]
fn evolve(alive: u8, n: u32) -> u8 {
    if alive == 1 {
        if n < 2 {
            0
        } else if n == 2 || n == 3 {
            1
        } else {
            0
        }
    } else {
        if n == 3 { 1 } else { 0 }
    }
}

struct Inboxes {
    top: Vec<AtomicU8>,    // сосед сверху пишет сюда
    bottom: Vec<AtomicU8>, // сосед снизу пишет сюда
}

fn make_inboxes() -> Inboxes {
    // создаем буферы для верхней и нижней граничных строк потока
    Inboxes {
        top: (0..COLS).map(|_| AtomicU8::new(0)).collect(),
        bottom: (0..COLS).map(|_| AtomicU8::new(0)).collect(),
    }
}

fn main() {
    let threads_n = THREADS.min(ROWS).max(1); // проверяем что потоков не больше строк

    // Сколько строк на поток
    let base = ROWS / threads_n;
    // Сколько строк остаётся (прибавим к последнему потоку)
    let rem = ROWS % threads_n;

    let barrier = Arc::new(Barrier::new(threads_n));

    // Для каждого потока создаем буферы для обмена граничными (по вертикали) строками
    let inboxes: Vec<Arc<Inboxes>> = (0..threads_n).map(|_| Arc::new(make_inboxes())).collect();

    let start = Instant::now();

    let mut thread_handles = Vec::with_capacity(threads_n);

    for tid in 0..threads_n {
        // строки для текущего потока (для последнего потока + остаток)
        let my_rows = if tid == threads_n - 1 {
            base + rem
        } else {
            base
        };

        // номера потоков-соседей (замыкаем по кругу)
        let up = (tid + threads_n - 1) % threads_n;
        let down = (tid + 1) % threads_n;

        // создаем ссылки на
        let b = barrier.clone();
        let me = inboxes[tid].clone();
        let up_in = inboxes[up].clone();
        let down_in = inboxes[down].clone();

        thread_handles.push(thread::spawn(move || -> u64 {
            // Старые строки матрицы
            let mut local = vec![0u8; my_rows * COLS];
            // Новые строки матрицы
            let mut next = vec![0u8; my_rows * COLS];

            // скармливаем сид + tid для получения разных значений на каждом потоке
            let mut rng =
                StdRng::seed_from_u64(SEED ^ (tid as u64).wrapping_mul(0x9E3779B97F4A7C15));
            // заполняем полосу случайными 0 и 1
            for x in &mut local {
                *x = if rng.random_bool(0.5) { 1 } else { 0 };
            }

            for _ in 0..STEPS {
                // ------ 1: обновляем границы
                // отправляем верхнюю и нижнюю строки соседям
                let last_off = (my_rows - 1) * COLS;
                for j in 0..COLS {
                    // верхняя строка -> up.bottom
                    up_in.bottom[j].store(local[j], Ordering::Release);
                    // нижняя строка -> down.top
                    down_in.top[j].store(local[last_off + j], Ordering::Release);
                }
                // Ждем пока все потоки отправят свои граничные строки
                b.wait();

                // ------ 2: вычисляем следующее состояние для всех строк этого потока
                for i in 0..my_rows {
                    // смещение для текущей строки
                    let row_off = i * COLS;
                    // флаги. Является ли верхняя/нижняя строка граничной?
                    let up_is_inbox = i == 0;
                    let dn_is_inbox = i + 1 == my_rows;

                    // проходим по всем столбцам
                    for j in 0..COLS {
                        let jl = if j == 0 { COLS - 1 } else { j - 1 };
                        let jr = if j + 1 == COLS { 0 } else { j + 1 };

                        let mut n: u32 = 0;

                        // верзняя часть
                        if up_is_inbox {
                            // берем атомики из буфера
                            n += me.top[jl].load(Ordering::Acquire) as u32;
                            n += me.top[j].load(Ordering::Acquire) as u32;
                            n += me.top[jr].load(Ordering::Acquire) as u32;
                        } else {
                            let up_off = (i - 1) * COLS;
                            n += local[up_off + jl] as u32;
                            n += local[up_off + j] as u32;
                            n += local[up_off + jr] as u32;
                        }

                        // лево и право
                        n += local[row_off + jl] as u32;
                        n += local[row_off + jr] as u32;

                        // низ
                        if dn_is_inbox {
                            // берем атомики из буфера
                            n += me.bottom[jl].load(Ordering::Acquire) as u32;
                            n += me.bottom[j].load(Ordering::Acquire) as u32;
                            n += me.bottom[jr].load(Ordering::Acquire) as u32;
                        } else {
                            let dn_off = (i + 1) * COLS;
                            n += local[dn_off + jl] as u32;
                            n += local[dn_off + j] as u32;
                            n += local[dn_off + jr] as u32;
                        }

                        // Вызываем эволюцию и записываем в next
                        let alive = local[row_off + j];
                        next[row_off + j] = evolve(alive, n);
                    }
                }
                // Ждем пока все потоки подсчитают новое состояние
                b.wait();

                // ------ 3: меняем старое и новое состояние местами
                std::mem::swap(&mut local, &mut next);
                // Ждем пока все потоки закончат обновление состояния
                b.wait();
            }

            // Вычисляем контрольную сумму по локальному куску
            local.iter().map(|&x| x as u64).sum()
        }));
    }

    // Собираем контрольные суммы от всех потоков
    let mut checksum = 0u64;
    for h in thread_handles {
        checksum = checksum.wrapping_add(h.join().unwrap());
    }

    println!("{} ms (checksum={})", start.elapsed().as_millis(), checksum);
}
\end{lstlisting}

\begin{lstlisting}[caption={Исходный код программы для задачи 2}, label={lst:cargo_toml}]
    use parking_lot::RwLock;
use rand::{rngs::ThreadRng, Rng};
use std::collections::{HashSet, LinkedList};
use std::sync::Arc;
use std::thread;
use std::time::Instant;

const THREADS: usize = 16;
const COUNT: usize = 1_000_000;

fn contains(list: &LinkedList<i32>, v: i32) -> bool {
    list.iter().any(|&x| x == v)
}

fn worker(num_values: usize, list: Arc<RwLock<LinkedList<i32>>>) {
    let mut rng: ThreadRng = rand::thread_rng();

    for _ in 0..num_values {
        let v: i32 = rng.gen_range(0..=1000);

        // 1) Проверка под read-lock
        {
            let guard = list.read();
            if contains(&guard, v) {
                continue;
            }
        }

        // 2) Запись под write-lock + повторная проверка
        {
            let mut guard = list.write();
            if !contains(&guard, v) {
                guard.push_back(v);
            }
        }
    }
}

fn main() {
    let start_time = Instant::now();
    let list = Arc::new(RwLock::new(LinkedList::<i32>::new()));

    let mut thread_handles = Vec::with_capacity(THREADS);
    for _ in 0..THREADS {
        let l = Arc::clone(&list);
        thread_handles.push(thread::spawn(move || worker(COUNT, l)));
    }

    // Ждем пока все потоки завершатся
    for h in thread_handles {
        h.join().unwrap();
    }

    // Вывод результата
    let values: Vec<i32> = {
        let guard = list.read();
        guard.iter().copied().collect()
    };

    // print!("Result list: ");
    // for v in &values {
        // print!("{v} ");
    // }
    // println!();
    let elapsed = start_time.elapsed().as_millis();
    println!("Elapsed time: {} ms", elapsed);

    // Проверка на дубли
    let mut seen = HashSet::new();
    for &v in &values {
        if !seen.insert(v) {
            panic!("Duplicate value found: {v}");
        }
    }
    println!("No duplicates found. Total unique values: {}", seen.len());
}

\addcontentsline{toc}{section}{Вывод}
\section*{Вывод}\label{Sect::conclusion}

В ходе выполнения лабораторной работы были реализованы две задачи, требующие использования различных механизмов синхронизации потоков. Первая задача, связанная с барьерной синхронизацией, продемонстрировала эффективное распределение вычислений между потоками при моделировании клеточного автомата. Вторая задача, использующая синхронизацию чтения и записи, показала важность правильного управления доступом к общим данным для предотвращения гонок и обеспечения целостности данных. В первом случае полученные результаты замеров времени выполнения программ подтвердили эффективность выбранных подходов к синхронизации в многопоточных приложениях. Однако во втором случае наблюдалось увеличение времени выполнения с ростом количества потоков, что связано с накладными расходами на управление блокировками при использовании RWLock. В целом, работа позволила углубить понимание механизмов синхронизации в параллельном программировании и их влияния на производительность приложений.
