# Parallel and Distributed Computing

<img align=right src="https://upload.wikimedia.org/wikipedia/commons/thumb/7/7b/An_illustration_of_the_dining_philosophers_problem.png/960px-An_illustration_of_the_dining_philosophers_problem.png" height="50px" width="50px">

This course was mainly about concepts of parallel programming.
We covered mechanisms of synchronization and some frameworks for parallel and distributed computing.

Here are [tasks](./tasks) and [reports](./reports) for each lab.

1. [Lab1](./src/lab1/README.md) is about parallel matrix multiplication using threads in Rust.
2. [Lab2](./src/lab2/README.md) is about solving equations using Jacobi method in parallel using MPI.
3. [Lab3](./src/lab3/README.md) is about solving equations using Jacobi method in parallel using OpenMP.
4. [Lab4](./src/lab4/README.md) is about implementing a dining philosophers problem solution using Waiter.
5. [Lab5](./src/lab5/README.md)'s first part is about implementing game of life variation with barrier multi-thread synchronization and the second part is about rwlocks.
