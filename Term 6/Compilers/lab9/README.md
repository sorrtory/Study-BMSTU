# Лабораторная работа 3.3: семантический анализ

Решение построено на основе лабораторной работы 2.2. Парсер принимает
объявления типов и констант подмножества Pascal, строит AST, выполняет
семантическую проверку и выводит:

- значения всех констант, включая элементы перечислений;
- размеры всех объявленных типов;
- координату и описание первой найденной ошибки.

## Запуск

```sh
python3 main.py assets/input.txt
```

Без аргумента используется файл `assets/input.txt`.

## Тестирование

```sh
sh tests/run.sh
```

## Структура

- `main.py` — AST, грамматика и семантический анализатор;
- `parser_edsl.py` — учебная библиотека построения парсеров;
- `assets/input.txt` — полный пример входной программы;
- `tests/` — автоматические тесты;
- `docs/implementation.md` — подробное объяснение решения и теории.
- `docs/defense-guide.md` — сценарий защиты и ответы на вопросы.
