# Короткая шпаргалка для сдачи 3.3

## 1. Что сказать в начале

В 2.2 был синтаксический анализатор: он строил AST для объявлений типов
и констант Pascal.

В 3.3 добавлена следующая фаза компилятора: семантический анализ.
После построения AST запускается `Program.check()`. Он создаёт
`SemanticContext` с таблицей символов и обходит дерево.

`check()` отвечает за порядок обхода и добавление объявлений.
`evaluate()` вычисляет значения констант и информацию о типах.

Если находится ошибка, выбрасывается `SemanticError` с координатой.
Если ошибок нет, выводятся значения констант и размеры типов.

Пояснение:

## 3. Что показать в коде

1. `analyze_file()`

```python
tree = build_parser().parse(source.read())
tree.check()
print(tree.format_result())
```

Сказать:

Первая строка строит AST. Вторая запускает семантический анализ.
Третья печатает результат.

2. `build_parser()`

Показать:

```python
parser = pe.Parser(NProgram, method=pe.EARLEY)
```

Сказать:

`NProgram` это стартовый символ грамматики.

3. `TypeDef.create()` или `NamedType.create()`

Сказать:

`create()` вызывается `parser_edsl` во время разбора и создаёт AST-узел.
Через `ExAction` туда попадают координаты.

4. `Program.check()`

Сказать:

Это старт семантического обхода AST.

5. `SymbolTable` и `SemanticContext`

Сказать:

Таблица символов хранит объявленные типы и константы. `add()` проверяет
повторы, `find()` проверяет использование объявленных имён.

6. `TypeDef.check()`

Сказать:

Правая часть типа вычисляется до добавления имени в таблицу. Поэтому
ссылки вперёд не разрешаются.

7. `EnumType.evaluate()`

Сказать:

Элементы перечисления добавляются как константы со значениями с нуля.

8. `ArrayType.evaluate()`, `SetType.evaluate()`, `RecordType.evaluate()`

Сказать:

Здесь считаются размеры типов.

## 4. Главная формула

```text
2.2: текст -> AST
3.3: текст -> AST -> check/evaluate -> ошибки или результат
```

`size` это размер одного значения типа в байтах.
`cardinality` это количество возможных значений конечного типа.

`cardinality` нужен для массивов и множеств:

```text
array 1..10 of INTEGER -> 10 * 2 байта
set of (red, green, blue) -> ceil(3 / 8) байт
```

## 5. Если спросят отличие check и evaluate

`check()` управляет обходом программы и работой с таблицей символов.

`evaluate()` вычисляет значение конкретного узла:

- для константы возвращает число;
- для типа возвращает `TypeInfo`;
- для массива, множества и записи считает размер.
