# Лабораторная работа 3.1

Тема: «Самоприменимый генератор компиляторов на основе предсказывающего
анализа».

Основная реализация находится в каталоге `src`. Подробная карта программных
файлов и команды запуска приведены в `src/README.md`.

## Файлы верхнего уровня

| Файл                         | Что находится внутри                                                                                                                        | Зачем нужен и где используется                                                           |
| ---------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------- |
| `README.md`                  | Краткая карта всей лабораторной работы.                                                                                                     | Помогает быстро найти исходники, отчёт и материалы для защиты.                           |
| `docs/`                      | Вспомогательные материалы для подготовки к защите.                                                                                          | Для сдачи программы не требуется, но помогает разобраться в теории и провести репетицию. |
| `docs/LAB_OVERVIEW.md`       | Короткое вводное описание: что взято из 2.3, как работает генератор, где грамматика, LL(1)-разбор, таблицы и калькулятор.                   | Читать первым, если нужно быстро восстановить общую картину лабораторной.                |
| `docs/DEFENSE_GUIDE.md`      | Подробный учебный конспект: теория LL(1), граница между работами 2.3 и 3.1, архитектура генератора, назначение типов и маршрут чтения кода. | Нужен для понимания лабораторной работы и подготовки ответов по теории.                  |
| `docs/DEFENSE_SCRIPT.md`     | Пошаговый сценарий демонстрации, команды, ожидаемые результаты и возможные вопросы преподавателя с ответами.                                | Используется непосредственно перед защитой и во время подготовки пробного показа.        |
| `docs/DEFENSE_CHEATSHEET.md` | Короткая шпаргалка: только шаги, команды и готовые фразы.                                                                                   | Удобно открыть непосредственно во время сдачи.                                           |
| `docs/MANUAL_TABLE_NOTES.md` | Короткий конспект про ручное построение LL(1)-таблиц, FIRST/FOLLOW и bootstrap-смысл ручной таблицы из 2.3.                                 | Помогает не запутаться, зачем ручная и сгенерированная таблицы совпадают.                |
| `report.md`                  | Файл отчёта по лабораторной работе.                                                                                                         | Должен быть заполнен перед сдачей по шаблону из задания.                                 |
| `3.1.map`                    | Служебный файл сопоставления для лабораторной работы.                                                                                       | В текущей реализации генератора не используется.                                         |
| `task/3.1 ... .html`         | Сохранённая локальная копия страницы задания.                                                                                               | Используется как справочник по исходным требованиям лабораторной работы.                 |
| `src/`                       | Ядро генератора, отдельный калькулятор, сгенерированные таблицы и вспомогательные тесты.                                                    | Это рабочий каталог лабораторной работы. Внутренняя структура описана в `src/README.md`. |

## Быстрая проверка

```bash
cd src
python3 tests/run_tests.py
```

Ожидаемые ключевые строки:

```text
Self-application table equality: True
Manual table equality: True
2+3*4 = 14
(2+3)*4 = 20
```

## Что относится к сдаче

Основная сдаваемая реализация:

- `src/generator.py`;
- `src/tests/demo_steps.sh` — bash-сценарий пошагового показа;
- `src/predictive_parser.py`;
- `src/grammar_parser.py`;
- `src/grammar_semantics.py`;
- `src/table_builder.py`;
- `src/table_emitter.py`;
- `src/generator_grammar.txt`;
- `src/calculator/` — обязательное отдельное тестовое приложение;
- `src/generated/` — результаты генерации для демонстрации самоприменения и
  работы калькулятора;
- `report.md` — отчёт.

Вспомогательные материалы:

- `src/tests/` — автоматическая проверка перед защитой;
- `docs/` — конспект и сценарий защиты;
- `task/` — локальная копия условия;
- `3.1.map` — служебный файл.

## Материалы для подготовки

1. Для понимания теории и кода открыть `docs/DEFENSE_GUIDE.md`.
2. Для репетиции сдачи открыть `docs/DEFENSE_SCRIPT.md`.
3. Для короткой шпаргалки на сдаче открыть `docs/DEFENSE_CHEATSHEET.md`.
4. Для повторения ручного построения таблиц открыть `docs/MANUAL_TABLE_NOTES.md`.
5. Для быстрого восстановления общей картины открыть `docs/LAB_OVERVIEW.md`.
6. Для просмотра назначения конкретного программного файла открыть
   `src/README.md`.
