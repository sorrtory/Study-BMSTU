## 1. Коротко объяснить лабораторную

Сказать:

> Эта работа продолжает лабораторную 2.3. Там был готов предсказывающий
> анализатор языка описания грамматик с ручной таблицей. Здесь я добавил
> семантический анализ дерева, построение FIRST и FOLLOW, генерацию LL(1)-
> таблицы и вывод таблицы как Python-исходника. Затем проверил самоприменение
> генератора и сделал отдельный калькулятор.

## 2. Показать структуру файлов

```bash
find . -maxdepth 2 -type f | sort
```

Сказать:

> Основной код генератора лежит в корне `src`. Калькулятор вынесен в
> `calculator/`, сгенерированные таблицы лежат в `generated/`, а
> автоматическая проверка — в `tests/`.

Кратко назвать главные файлы:

```text
grammar_parser.py      — лексер и ручная таблица из 2.3
grammar_semantics.py   — дерево превращается в правила грамматики
table_builder.py       — FIRST, FOLLOW и LL(1)-таблица
table_emitter.py       — вывод таблицы как Python-кода
generator.py           — связывает все этапы
predictive_parser.py   — общий предсказывающий анализатор
```

Если хочется показывать всё через один файл, открыть `tests/demo_steps.sh`:
можно комментировать отдельные блоки команд по мере демонстрации.

## 3. Показать грамматику генератора

```bash
cat generator_grammar.txt
```

Сказать:

> Это грамматика входного языка генератора, записанная на самом входном языке.
> Она нужна для самоприменения.

## 4. Показать самоприменение

Первый запуск с ручной таблицей из 2.3:

```bash
python3 generator.py generator_grammar.txt generated/generated_input_table.py \
  --mode enum
```

Второй запуск со сгенерированной таблицей:

```bash
python3 generator.py generator_grammar.txt generated/generated_input_table_2.py \
  --mode enum --bootstrap-table generated/generated_input_table.py
```

Сравнить результаты:

```bash
cmp generated/generated_input_table.py generated/generated_input_table_2.py
echo $?
```

Ожидаемый результат:

```text
0
```

Сказать:

> В первый раз использовалась ручная таблица из 2.3. Во второй раз она была
> заменена автоматически сгенерированной таблицей. Файлы совпали, значит
> генератор самоприменим.

## 5. Показать калькулятор

Показать грамматику:

```bash
cat calculator/arithmetic_grammar.txt
```

Сказать:

> Это грамматика калькулятора из индивидуального варианта. Она поддерживает
> числа, скобки, сложение и умножение. Умножение имеет более высокий приоритет.

Сгенерировать таблицу:

```bash
python3 generator.py calculator/arithmetic_grammar.txt generated/calc_table.py \
  --mode string
```

Запустить калькулятор:

```bash
python3 -m calculator.calculator
```

Ввести:

```text
(2+3)*4
```

Ожидаемый результат:

```text
20
```

Сказать:

> Калькулятор является отдельной программой. Он использует сгенерированную
> таблицу и общий предсказывающий анализатор.

## 7. Если попросят показать ошибку LL(1)

```bash
printf '`axiom S `is "a" `or "a" "b" `end\n' > /tmp/not_ll1.txt
python3 generator.py /tmp/not_ll1.txt /tmp/not_ll1_table.py --mode string
```

Сказать:

> Две продукции пытаются занять одну ячейку таблицы для lookahead `"a"`.
> Поэтому грамматика не является LL(1), и генерация прерывается.
