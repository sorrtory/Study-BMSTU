# Короткое описание лабораторной

Лаба 3.1 строится поверх лабы 2.3. Из 2.3 мы берём готовую основу:
лексер входного языка, дерево разбора, ручную LL(1)-таблицу и общий
предсказывающий анализатор. В 3.1 к этому добавлен генератор таблиц:
он читает описание грамматики, проверяет её семантически, строит множества
FIRST/FOLLOW и по ним собирает LL(1)-таблицу.

Общая цепочка такая:

```text
текст грамматики
-> лексер
-> предсказывающий LL(1)-анализатор
-> дерево разбора
-> семантический анализ
-> объект Grammar
-> FIRST/FOLLOW
-> LL(1)-таблица
-> Python-файл с PARSE_TABLE
```

Грамматика входного языка генератора лежит в `src/generator_grammar.txt`.
Именно она описывает формат файлов вида:

```text
`axiom E `is T E1 `end
E1 `is "+" T E1 `or `epsilon `end
```

Разбор этой грамматики выполняет общий предсказывающий анализатор из
`src/predictive_parser.py`. Он не знает конкретную грамматику заранее:
ему передают таблицу разбора, стартовый нетерминал и набор нетерминалов.

В начале используется ручная таблица из `src/grammar_parser.py`. Это часть,
оставшаяся от 2.3: она нужна, чтобы первый раз прочитать описание грамматики
самого генератора. После этого `src/generator.py` строит уже автоматическую
таблицу и записывает её в `src/generated/generated_input_table.py`.

Самоприменимость показывается вторым запуском: генератор читает свою же
грамматику уже не ручной таблицей, а сгенерированной:

```bash
python3 generator.py generator_grammar.txt generated/generated_input_table_2.py \
  --mode enum \
  --bootstrap-table generated/generated_input_table.py
```

Если грамматика не LL(1), таблица не строится. Конфликт возникает, когда для
одного нетерминала и одного lookahead-токена подходят две разные продукции.
Обычно это видно по пересечению FIRST/FIRST или FIRST/FOLLOW при `epsilon`.

Калькулятор вынесен отдельно в `src/calculator/`. Его грамматика лежит в
`src/calculator/arithmetic_grammar.txt`. Для неё генератор строит отдельную
таблицу `src/generated/calc_table.py`, а приложение `src/calculator/calculator.py`
использует эту таблицу, чтобы разобрать выражение и посчитать результат.

Главные файлы:

- `src/generator.py` - CLI генератора таблиц.
- `src/generator_grammar.txt` - грамматика языка описания грамматик.
- `src/grammar_parser.py` - лексер, типы токенов и ручная таблица из 2.3.
- `src/predictive_parser.py` - общий LL(1)-анализатор.
- `src/grammar_semantics.py` - семантическая проверка дерева грамматики.
- `src/table_builder.py` - FIRST, FOLLOW и построение LL(1)-таблицы.
- `src/table_emitter.py` - запись таблицы в Python-исходник.
- `src/generated/` - сгенерированные таблицы.
- `src/calculator/` - тестовое приложение калькулятора.
- `src/tests/demo_steps.sh` - короткий сценарий показа команд.
