# Лабораторная работа 3.1

Каталог `src` разделён по назначению:

```text
src/
├── generator.py                 # точка входа генератора
├── predictive_parser.py         # общий LL(1)-анализатор
├── grammar_parser.py            # лексер языка грамматик и ручная таблица 2.3
├── grammar_semantics.py         # семантический анализ дерева
├── table_builder.py             # FIRST, FOLLOW и построение таблицы
├── table_emitter.py             # вывод таблицы как Python-кода
├── generator_grammar.txt        # грамматика генератора на ней самой
├── calculator/                  # отдельное тестовое приложение
├── generated/                   # автоматически порождённые таблицы
└── tests/                       # проверки и интерактивные шаги демонстрации
```

## Что относится к основной лабораторной

Эти файлы образуют самоприменимый генератор и являются основной частью работы
3.1:

| Файл                    | Что находится внутри                                                                                                                                        | Зачем нужен                                                                                                        | Где используется                                                                                                                         |
| ----------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------- |
| `generator.py`          | CLI генератора, загрузка ранее сгенерированной таблицы и последовательный вызов всех этапов.                                                                | Это точка входа основной программы.                                                                                | Запускается вручную и из `tests/run_tests.py`.                                                                                           |
| `predictive_parser.py`  | Общие типы `Token`, `ParseNode`, протокол `Lexer`, исключение `ParserError` и универсальный стековый класс `PredictiveParser`.                              | Содержит единый алгоритм LL(1)-разбора для разных языков.                                                          | Импортируется в `grammar_parser.py`, `grammar_semantics.py` и `calculator/calculator.py`.                                                |
| `grammar_parser.py`     | Лексер входного языка описания грамматик, перечисление `TokenType`, ручная таблица `build_manual_table()`, настройка общего парсера и экспорт дерева в DOT. | Это часть, основанная на лабораторной работе 2.3. Ручная таблица нужна для первого запуска раскрутки.              | Используется в `generator.py`. Тип `TokenType` также нужен семантическому анализатору, генератору исходников и таблицам из `generated/`. |
| `grammar_semantics.py`  | Структуры `GrammarSymbol`, `Production`, `GrammarSpec`, класс `GrammarTreeBuilder` и функция `build_grammar_spec()`.                                        | Преобразует дерево разбора в набор правил. Проверяет наличие одной аксиомы и ссылки на неопределённые нетерминалы. | Вызывается из `generator.py`. Его структуры используются в `table_builder.py` и `table_emitter.py`.                                      |
| `table_builder.py`      | Функции вычисления `FIRST`, `FOLLOW`, построения LL(1)-таблицы и обнаружения конфликтов.                                                                    | Реализует основной алгоритм лабораторной работы 3.1.                                                               | Вызывается из `generator.py`. Тип таблицы и `EPSILON_SYMBOL` используются в `table_emitter.py`.                                          |
| `table_emitter.py`      | Функция `emit_python_table()` и вспомогательное форматирование продукций.                                                                                   | Записывает таблицу как Python-исходник со словарём `PARSE_TABLE`. JSON и сериализация не используются.             | Вызывается из `generator.py` после успешного построения таблицы.                                                                         |
| `generator_grammar.txt` | Грамматика входного языка генератора, записанная на самом входном языке.                                                                                    | Нужна для самоприменения: генератор строит таблицу собственного парсера.                                           | Передаётся в `generator.py` при создании таблиц в `generated/`.                                                                          |

## Отдельное приложение-калькулятор

Каталог `calculator/` содержит пример рабочего языка. Калькулятор требуется
условием, но логически отделён от самого генератора.

| Файл                                | Что находится внутри                                                                                  | Зачем нужен                                                            | Где используется                                                                                  |
| ----------------------------------- | ----------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------- |
| `calculator/__init__.py`            | Маркер Python-пакета.                                                                                 | Позволяет запускать калькулятор как модуль.                            | Используется Python при команде `python3 -m calculator.calculator`.                               |
| `calculator/arithmetic_grammar.txt` | Грамматика выражений с числами, скобками, сложением и умножением.                                     | Нужна для генерации таблицы тестового рабочего языка.                  | Передаётся в `generator.py` при создании `generated/calc_table.py`.                               |
| `calculator/calculator.py`          | Лексер арифметических выражений, настройка общего `PredictiveParser` и вычисление значения по дереву. | Демонстрирует применение сгенерированной таблицы отдельной программой. | Импортирует `generated/calc_table.py`. Запускается вручную и проверяется из `tests/run_tests.py`. |

## Раскрутка генератора

Все команды выполняются из каталога `src`.

Сначала таблица входного языка строится с использованием ручной таблицы из
`grammar_parser.py`:

```bash
python3 generator.py generator_grammar.txt generated/generated_input_table.py \
  --mode enum --sets
```

Затем генератор применяется к собственной грамматике уже через сгенерированную
таблицу:

```bash
python3 generator.py generator_grammar.txt generated/generated_input_table_2.py \
  --mode enum --bootstrap-table generated/generated_input_table.py
```

Результаты должны совпасть:

```bash
cmp generated/generated_input_table.py generated/generated_input_table_2.py
echo $?
```

Ожидаемый код: `0`.

## Таблица для калькулятора

```bash
python3 generator.py calculator/arithmetic_grammar.txt generated/calc_table.py \
  --mode string --sets
```

После этого запускается отдельное приложение:

```bash
python3 -m calculator.calculator
```

Пример:

```text
expression> 2+3*4
14
```
