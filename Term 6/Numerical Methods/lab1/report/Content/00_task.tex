\textbf{Дано:}

Функция $f(x) = e^x$, заданная конечным набором точек:
\[
y_i = f(x_i), \quad i = \overline{1, n}
\]
на отрезке $[a, b] = [0, 1]$: $a = x_0$, $b = x_n$, 
\[
x_i = a + ih, \quad \text{где } h = \frac{b - a}{n}
\]

\textbf{Найти:}

1. Интерполяционную функцию $y = g(x)$: 
\[
g(x_i) = f(x_i), \quad i = \overline{0, n}
\]

2. Значения интерполяционной функции в узлах интерполяции и в серединах
отрезков между узлами.

3. Вычислить разницу между значениями интерполяционной функции и фактическим значением изначально заданной функции.
