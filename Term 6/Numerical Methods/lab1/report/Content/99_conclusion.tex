В ходе лабораторной работы был изучен метод аппроксимации функции при помощи интерполяции кубическим сплайном. Для функции $f(x)=e^x$ на отрезке $[0,1]$ было выполнено табулирование значений на равномерной сетке ($n=10$). Для нахождения коэффициентов сплайна была составлена трёхдиагональная система линейных уравнений, решённая методом прогонки при границах $C_0=0$ и $C_n=0$.

Значения в аппроксимации относительно исходной функции в узлах интерполяции получилось вычислить с погрешностью 0\%, а в серединах отрезков с 0.01\%.
