"решение СЛАУ с 3-х диагоналной матрицей методом прогонки"



Дано: СЛАУ с 3-х диаг матрицей



В вектороно-матричном виде



Ax = d, A пренадлежит R^(n\*n), d пренадлежит R



Матрица:

A = ( b1 c1 ....

&nbsp;   (  a1 b2 c2 ...

&nbsp;   (	.

&nbsp;   (	.

&nbsp;		a(n-1) b(n) )



Количество диагоналей l = 2s + 1 кол - во диагоналей

S - ширина ленты



Найти x пренадлежащий R^n





фОРМУЛА 



{ b1x1 +c1x2 = d1,

&nbsp; a1x1 + b2x2 + c2x3 = d2,

&nbsp; ...,

&nbsp; ai-1xi-1 + bixi + cixi+1 = di,

&nbsp; ....,

&nbsp; an-1xn-1 + bnxn = dn }





Преобразуем 



x1 = -(c1/b1)x2 + d1/b1, b1 != 0 

пусть -(c1/b1) = k1 , d1/b1 = m1



Решение будет такого вида: xi = kix(i+1) + mi , где i = n-1 …



Подставляю в следующие уравнение 

a1(k1x2 + m1) + (b2x2 + c2x3) = d2

Выразим x2 через x3



x2 = - c2/(a1k1+b2) \* x3 + (d2 - a1m1)/(a1d1 + b2)



Пусть - c2/(a1k1+b2) = k2 , (d2 - a1m1)/(a1k1 + b2) = m2







Тк все последующие строчки кроме последней имеют такую же структуру, то можно проиндуыировать получим формулу 


ki = -ci/(a(i-1) \* k(i-1) + bi)
mi = (di - a(i-1)m(i-1))/(a(i-1) k(i-1) + bi)


Выразим xn 



xn = (dn - a(n-1) \* m(n-1)) / (a(n-1) \* k(n-1) + bn))
