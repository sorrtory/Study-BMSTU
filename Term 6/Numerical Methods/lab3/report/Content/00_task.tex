\textbf{Задание}

Найти $\int_a^b{f(x)dx}$ по  формуле прямоугольников, трапеций и Симпсона с погрешностью $\epsilon = 10^{-3}$. 
Сравнить требуемое число разбиений для каждого варианта.

\textbf{Вариант 22} 
\begin{enumerate}
  \item $a = 0.5$, $b = 2*e$;
  \item $f(x) = \ln(2*x)$
\end{enumerate}

Для уточнения результата использовать метод Ричардсона.
