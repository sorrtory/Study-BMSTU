# Лабораторная работа 3

Простейший компилятор на базе LLVM для языка с одной функцией `main`.
Компилятор читает программу из файла, переданного первым аргументом, или из
`stdin`, строит LLVM IR и печатает его в консоль.

## Синтаксис

```text
a = 5
b = 3
c = a + b * 2

if (c > 10) then
    c = c - 1
else
    c = c + 1
end

while (c) do
    c = c - 1
end

return c
```

Поддерживаются:

- целочисленные константы и переменные типа `i32`;
- присваивание результата выражения переменной;
- операции `+`, `-`, `*`, `/`;
- сравнения `<`, `<=`, `>`, `>=`, `==`, `!=`, возвращающие `0` или `1`;
- управляющие конструкции `if ... then ... else ... end` и
  `while ... do ... end`;
- `return` из единственной функции `main`.

## Сборка и запуск

```bash
make -C lab3
./lab3/lab3 < lab3/example.txt
```

Альтернативно:

```bash
cmake -S lab3 -B lab3/build
cmake --build lab3/build
./lab3/build/lab3 lab3/example.txt
```
