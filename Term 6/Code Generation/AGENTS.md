# Лабораторные работы по курсу "Генерация оптимального кода"

Этот репозиторий содержит материалы и примеры для лабораторных работ по курсу
"Генерация оптимального кода" в рамках учебной программы российского университета.

## Содержание

- [Лабораторная работа 1](./lab1/)
- [Лабораторная работа 2](./lab2/)
- [Лабораторная работа 3](./lab3/)
- [Лабораторная работа 4](./lab4/)

Внутри каждой папки с лабораторной работой находится условие этой лабораторной.

- [./lab1/1-task.md](./lab1/1-task.md) - условие первой лабораторной работы. [Методичка](./materials/gcc-plugins.pdf). Лекции по GCC: [GCC Internals](./materials/lectures/02.GCC_internals.v1.pdf)
- [./lab2/2-task.md](./lab2/2-task.md) - условие второй лабораторной работы. [LLVM методичка](./materials/LLVM.v2.pdf)
- [./lab3/3-task.md](./lab3/3-task.md) - условие третьей лабораторной работы
- [./lab4/4-task.md](./lab4/4-task.md) - условие четвертой лабораторной работы

Условие нужно строго выполнить. Если в условии указано, что нужно реализовать определённый алгоритм, то нужно реализовать именно его, а не какой-то другой алгоритм, который может показаться более простым или удобным.

## Теоретические материалы

В папке [materials](./materials/) находятся теоретические материалы, которые могут помочь в выполнении лабораторных работ.
В частности, в папке [lectures](./materials/lectures/) находятся лекции, которые необходимо использовать.
Задача - максимально использовать эти материалы для выполнения лабораторных работ.
Лекции - первый источник информации! Но не стоит забывать про другие материалы.
