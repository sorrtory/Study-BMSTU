# Hello Func GCC Plugin

Второй пример из методички: плагин регистрирует свой `GIMPLE_PASS` после
построения SSA и GCC вызывает `execute` для каждой функции.

Это еще не полная первая лаба. Здесь мы только проверяем, что можем
подключиться к pass manager и получить имя текущей функции.

```sh
make test
```

Ожидаемый смысл вывода:

```text
func: add
func: main
Result: 5
```
