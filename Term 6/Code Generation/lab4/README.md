# Лабораторная работа 4

Простейший компилятор для маленького языка из третьей лабораторной. Фронтенд
оставлен тем же по смыслу: `Lexer` читает токены, `Parser` строит AST. После AST
начинается новая часть четвертой лабораторной: вместо LLVM строится свой IR,
CFG и SSA-форма.

## Что реализовано

- фронтенд из лабораторной 3: присваивания, `if ... then ... else ... end`,
  `while ... do ... end`, `return`, арифметика и сравнения;
- CFG из базовых блоков;
- простой IR для выражений, переходов и возврата;
- построение SSA через доминаторы, dominance frontier и phi-функции;
- вывод GraphViz в `cfg.dot`.

## Чем отличается от лабораторной 3

В лабораторной 3 после AST сразу генерируется LLVM IR.

В лабораторной 4 цепочка другая:

```text
input -> Lexer -> Parser -> AST -> свой IR -> CFG -> SSA -> cfg.dot
```

LLVM здесь не используется. Нужны именно свой IR, граф потока управления и
перевод этого IR в SSA.

## Запуск

```bash
make -C lab4
./lab4/lab4 lab4/example.txt
```

После запуска программа печатает IR до и после SSA, а также создает `cfg.dot`.
Картинку можно получить так:

```bash
dot -Tpng cfg.dot -o cfg.png
```
